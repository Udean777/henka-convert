# Local conversion format matrix

This catalog describes formats that the application can accept and produce without relying on browser-native encoders. It is intentionally separate from browser capability probes. A format belongs in an output list only when a local encoder is bundled and the conversion route is implemented.

## Conversion rules

- Output choices stay the same across browsers because the encoders are supplied by the application.
- The list is not a promise that every pair of formats is meaningful. Each converter validates the selected target and reports unsupported or malformed input in plain language.
- HEIC/HEIF input is decoded locally; HEIC output is encoded locally through `elheif`, compiled from libheif, libde265, and kvazaar. The package bundles its WebAssembly module for browser use. The included third-party component licenses must accompany distribution.
- Raster-to-SVG output is a convenience wrapper containing a PNG image. It is not a vector trace.
- Image and PDF conversions use the first frame of animated GIFs and the first page of multi-page TIFFs in this release.
- Spreadsheet conversion focuses on cell values. It does not promise workbook fidelity for formatting, macros, formulas, or unsupported features.
- CSV/TSV values remain text; their first row supplies unique, non-empty headers. Blank cells are emitted as empty values. Spreadsheet dates and formulas are exported as the displayed/cached cell value, not as date serials or formulas. Text values and displayed number formats such as `00000` retain leading zeros; an unformatted numeric cell cannot recover zeros that were not stored in the source value.
- Audio and video use one single-thread FFmpeg.wasm core. The first conversion loads an approximately 31 MB core as an application asset; the selected files are still processed in the browser. The app shows plain format names, and `media/profiles.ts` defines the codec settings for each output.
- The bundled `@ffmpeg/core` package is marked GPL-2.0-or-later. Review its license and any included codec licensing requirements before distributing a production build.
- Audio accepts files up to 20 MB and 10 minutes; video accepts files up to 20 MB and 60 seconds. Video inputs above 7,680 px on either side or 33.2 MP are rejected; accepted videos are resized to fit 1920 × 1080. Output size limits are 128 MB for audio and 200 MB for video.
- DOCX is normalized through semantic HTML and plain text before output. DOCX export creates a basic document from text, headings, lists, and simple table rows; it does not preserve original layout or advanced Word features. HTML outputs are sanitized to remove scripts and active content.
